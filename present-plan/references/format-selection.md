# Format selection

Choose one primary format from the plan's dominant structure. Add another medium only when it serves a distinct consumption setting.

| Plan shape | Primary format | Use when |
| --- | --- | --- |
| Mostly sequential | Journey or timeline | Order and milestones carry the meaning |
| Parallel work with handoffs | Swimlanes or subway map | Coordination and bottlenecks matter |
| Material alternatives | Branching decision map | Choices change later stages |
| User or system transformation | Before-intervention-after storyboard | Causality matters more than scheduling |
| Allocation across phases | Stacked allocation view | The key question is where time or resources go |
| Stakeholder tradeoffs | Compressed conversation | Objections and decisions are hard to absorb in formal prose |
| Executive approval | Short presentation or plan trailer | The audience needs direction, stakes, and the key decision |
| Eyes-free consumption | Narrated briefing | The audience cannot rely on the screen |

## Medium rules

### Static visual

Use a static visual when labels and connections fully explain the plan. Prefer this for the fastest first view.

### Interactive visual

Use interaction for selected-stage details, branch comparison, scenario changes, or guided playback. Keep the first render useful before any interaction.

### Conversation

Use a Slack-like exchange only to expose actual tradeoffs. Give each message one new fact, objection, answer, or decision. End with the resulting decision or unresolved question.

### Presentation

Use slides for meetings and asynchronous approval. Build around outcome, route, decision, risk, and proof; do not turn every stage into a slide by default.

### Audio

Use a single-voice briefing for speed. Use multiple voices only when distinct perspectives improve understanding. Always provide a written fallback and navigable stage markers when possible.

### Video

Use a 30-90 second animated walkthrough for distribution or executive orientation. Animate attention along the canonical visual; do not create unrelated decorative motion. Treat video as an export, not the only source of detail.

## Avoid

- A dashboard containing the same plan as a timeline, cards, table, and chart.
- Decorative color that implies categories without meaning.
- Fake precision, invented conflict, or fabricated stakeholder quotes.
- Narration that merely reads visible text.
- A cinematic export when a static map answers the question faster.
- Hiding a requested dimension behind a toggle when it can be shown clearly at once.
