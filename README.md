# skills

Personal AI agent skills and workflows.

## Included skills

| Skill | Purpose |
| --- | --- |
| [`coworker-chat`](coworker-chat/) | Use a concise, natural coworker conversation style. |
| [`present-plan`](present-plan/) | Turn complex plans into fast, layered visual briefings. |

## Installation

Clone the repository, then copy or symlink the skill directories you want into
the skills directory used by your agent.

```bash
git clone https://github.com/melnikov-s/skills.git
```

Each skill starts with a `SKILL.md` file and includes its supporting resources.
